Reader translation smoke test

A desktop reader can translate the visible article first. As the reader scrolls, new paragraphs enter the queue while completed translations remain available without another model call.

Independent requests allow the first translated paragraph to appear before the entire screen finishes. A bounded worker pool avoids overwhelming the provider with unnecessary connections.

Text discovery should reuse a page index rather than walking the full document repeatedly. Only changed subtrees need to be inspected when the website updates its content dynamically.

A translation cache must distinguish the target language and model. An incomplete response should never be treated as a completed translation, and interrupted requests must remain retryable.
